# Agents OpenMaster

Cette documentation définit une organisation multi-agent légère pour le dépôt. Elle
sert de contrat de collaboration ; elle n’ajoute aucun orchestrateur runtime.

- [`baseline.md`](baseline.md) : version, tests, structure et état de référence.
- [`architecture.md`](architecture.md) : flux applicatif et topologie de déploiement.
- [`routing.md`](routing.md) : domaines, ownership, Fast Path et handoffs.
- [`testing-and-safety.md`](testing-and-safety.md) : validation, sécurité et impact production.

Le produit reste piloté par [`ROADMAP.md`](../../ROADMAP.md) et l’architecture actuelle
par [`ARCHITECTURE.md`](../../ARCHITECTURE.md).
